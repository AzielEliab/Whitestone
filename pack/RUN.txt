Whitestone
==========

Author: Aziel Eliab

1. Unzip this folder.
2. In the whitestone folder, run:  node whitestone.mjs ui
3. Open the printed link and pick Criminal, Civil, or Divorce.

node whitestone.mjs --help    lists commands
node whitestone.mjs doctor    checks this copy

The app listens on 127.0.0.1 only. End & erase wipes the session.
This copy uses the bundled knowledge layer.

If node is not installed, from this same folder:

  python3 -m http.server 4173 --bind 127.0.0.1

Source: https://github.com/AzielEliab/Whitestone
