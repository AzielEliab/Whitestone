# Whitestone

A private session for Criminal, Civil, or Divorce procedure. Author: Aziel Eliab.

Lamb Lens: Service → Clarity → Peace.

## Start

1. Unzip this folder.
2. In the `whitestone` folder, run `node whitestone.mjs ui`.
3. Open the printed link and pick a practice area.

`node whitestone.mjs --help` lists commands. Add `--json` when a script needs JSON.

The app listens on 127.0.0.1 only. End & erase wipes the session. This copy uses the bundled knowledge layer.
